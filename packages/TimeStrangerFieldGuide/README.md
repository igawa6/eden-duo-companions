# Digimon Story Time Stranger: Time Stranger Field Guide

Companion 1.0.0 for Digimon Story Time Stranger (`010062E01FE0C000`), game version 1.2.2 (build `135C83CDEA06AEC2`).
Requires Eden Duo 1.2.0 or newer (runtime 19). Read-only: it reads the running game and never changes it.

A field guide on the second screen: the live area and party, all main missions with spoilers hidden until you show
them, side quests, the Digimon dex, the type chart, tips, items and an area guide. Portraits, icons, the menu font,
names, descriptions, prices, chests, wild Digimon and rewards are read from your own game files at run time; the
package ships no game pictures, text or data.

On any other game version every page says "Needs game version 1.2.2".

Features and screenshots: see the Digimon Story Time Stranger section of the repository README.
Build and test: [tools/digimon-time-stranger/README.md](../../tools/digimon-time-stranger/README.md).
