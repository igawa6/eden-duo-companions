# Kirby's Return to Dream Land Deluxe

A second-screen companion for Kirby's Return to Dream Land Deluxe, made by Fab.

| | |
|---|---|
| Title ID | `01006B601380E000` |
| Game version | 1.0.0, build `FA24EA3C3A512C07` (the only build the module reads) |
| Package | 1.0.0, `min_runtime` 17, native module required |
| Tested with | Eden Duo 1.3.0 on desktop; Android arm64 builds tested by the beta testers on an AYN Thor |
| Languages | The game's 15 languages, in its own text and fonts (Japanese, Korean and Chinese with their region fonts) |

## What the bottom screen shows

The page follows the game from the title screen to the staff roll:

- **Title and file select**: a tappable Start, the three save files with Kirby's face and the
  file's completion.
- **Mode select and main menu**: Story, Extra, the Magolor Epilogue, the Arena, the True Arena
  and Merry Magoland.
- **World map**: Pop Star and Halcandra rendered from the game's models. Tap a world to go
  straight there.
- **Stage**: lives, Point Stars, Energy Spheres, the souvenir, amiibo, the battery and a Pause
  button. Also the copy ability's description and moves from the game's pause pages, and options:
  a still or animated background, the top screen's HUD counters, and cheats.
- **Kirby's colours**: 86 colour presets, applied with a spray can. Each save file keeps its own,
  and more unlock through the story. The colour also shows on the world map and in Merry Magoland.
- **Boss fights**: the bottom screen shakes, is cut and shatters with Grand Doomer's and Magolor's
  attacks. Magolor Soul's second phase plays on the True Arena page.
- **Magolor Epilogue**: magic moves by technique level, the Heal and Magolor Blast gauge buttons,
  options, and the Master Crown finale.
- **Arena and True Arena**: Kirby and the next boss drawn from the game's models, with the round
  and the time.
- **Merry Magoland**: the plaza in four sections:
  - Minigames: tap a door or the globe to start an attraction;
  - Missions: pin up to five per file;
  - Masks: wear one with a tap;
  - Stamp Cards.

  While an attraction is played, the page shows its ticket, the pinned missions and the Magoland
  Tour's rounds.
- **Films and menus**: cutscenes darken the page behind the logo. Past Adventures, the Jukebox and
  the Theater close a curtain.
- **Credits**: the companion's credits roll over the game's staff roll.

## Game files

The package ships no game assets. The module (`native/modules/01006B601380E000.cpp` and
`kirby_*.cpp`, target `dsmod-kirby`) decodes every picture, model, font and text at runtime from
the player's own romfs. The only picture in the package, `art/battery.png`, was drawn for it.

The other files in `dualscreen/` are:

| File | Contents |
|------|----------|
| `FA24EA3C3A512C07.json` | The per-build data file for 1.0.0 |
| `kirby_font.txt` | The game font the module rasterises for the page text |
| `shatter.txt`, `finale.txt`, `soul.txt` | The boss effects' cut and piece plans |
| `colour_unlocks.txt` | When each colour unlocks |
| `credits.txt` | The credits shown over the staff roll |

`manifest.json` and the three effect plans are generated by `tools/kirby/gen_manifest.py`.
