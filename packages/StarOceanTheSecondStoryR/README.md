# Star Ocean: The Second Story R — dual-screen companion

Game: **STAR OCEAN THE SECOND STORY R** (Switch, title ID `010065301A2E0000`), update **1.0.1**
(build `D214BA64D902AEDA`). Tested on Eden Duo 1.3.5 (runtime 23) on an AYN Thor (Android, NCE).
`min_runtime` 22.

**Use NCE, not JIT.** It was developed and tested with NCE only.

The package ships **no game assets**. Every picture, the game's fonts and the words on the pages are read
at run time from the player's own game files and the game's own text; `dualscreen/pictures.idx` holds
only picture names and positions in those files. The companion reads the game and presses its buttons;
the only thing it writes is its own mailbox, for the optional Hide HUD switch.

## What it shows on the second screen

**Title screen:** the game's title screen (starfield, planet, globe and logo), with a Continue button
that presses A. The tabs appear once a save is loaded, and the page follows the game from then on:
Guide Map on the field and the world map, Battle when a battle starts.

**PARTY**
- **Roster:** the party in the game's Party Formation look (character art, level arc, HP / MP);
  Leader makes a member the leader through the game's own Party Formation menu.
- **Status:** HP / MP with their maximums, EXP and next level, ATK, DEF, HIT, AVD, INT, LUC, STM,
  CRT, GUTS, elements, status ailments, Friendship Level, Talents and Favorite Food (once the game
  reveals it).
- **Equipment:** the seven slots with the game's item icons, beside the member's full-body art.
  Tapping a slot opens the game's Equipment screen.
- **Special Arts/Spells:** every art or spell with its level and BP cost, the arts set on L and R.
  L / R open the game's Special Arts/Spells screen on that member; Improve opens Improve >
  Special Arts/Spells.
- **Skills:** IC/Specialty Skills and Combat Skills with their levels and SP / BP costs (scrolling),
  IC / Specialty / Super Specialty levels; Improve opens the matching Improve screen.

**GUIDE MAP**
- **Map:** the game's own minimap of the area and floor you are in, or the Expel / Nede world map,
  with your position and facing, and the game's own icons (towns, dungeons, the destination,
  sub-events, Private Actions, save points, shops, entrances, enemies, NPCs). Tap the map to switch
  between the zoomed and the whole map.
- **Place and floor names** and the **next objective**, in the game's words.
- **Party bar:** the battle members' portraits, levels, HP / MP and the LEADER tag; Fol.
- **Shortcuts:** Guide Map, Items, IC/Specialty, Quick Heal, Camp Menu and Switch PA, pressed with the
  game's own buttons.
- **Hide HUD (optional):** hides the top screen's shortcut list, minimaps, place names, field icons
  and field mode marker, and in battle the party status, button guide, bonus gauge, assist panel and
  item cool time. Game files on disk are not changed; the optional Hide HUD switch patches game code in
  memory while the game runs (a small helper in the game's per-frame update, off by default and off at each
  launch). Switching it off restores the pieces. If the companion is unloaded (package reload, companion off)
  while the switch is on, the pieces are handed their own scale back. While the second screen is hidden the
  module is not sampled (NO_TICK_WHEN_HIDDEN), so a switch that is on stays on until the screen is shown again.

**MISSIONS**
- Challenge Missions in the game's four rank tabs and Guild Missions, with each mission's progress
  (e.g. 3 / 10) and the game's Complete / Incomplete. Tapping a mission opens it in the game's own
  Missions menu.

**BATTLE**
- The controlled member's art with level, HP / MP, and the other members' cards; tapping a card
  switches control to that member (the game's ZR + stick).
- Status ailments on each member (Poison, Paralysis, Petrification, Confusion, Silence) with the
  game's own battle icons.
- The bonus gauge in the game's look and font, and the Assault Action members.
- Buttons with the game's own button icons, lit when tapped: Attack (A), Counter (B), the arts set
  on L and R, Items, Spells, Strategy, Escape, and the Y order.

## How it works

- `dualscreen/manifest.json`: the pages, generated by `tools/so2r/gen_manifest.py`.
- `dualscreen/D214BA64D902AEDA.json`: the per-build data file (marks the supported build; the module
  reads every value).
- `dualscreen/plans/D214…0000.json`: a small per-build code patch for the optional Hide HUD, checked by
  Eden against the game's own bytes before it is applied. It runs a tiny helper from the game's own
  per-frame update that scales the chosen HUD pieces to 0 and back, through the game's own Unity
  calls, only while the switch is on. Built from `tools/so2r/hidehud/stub.S`.
- `dualscreen/pictures.idx`: where each picture and the font sit in the player's game files (names,
  sizes and positions only).
- The native module (`native/modules/so2r/010065301A2E0000.cpp`) reads the game's memory and files,
  decodes the pictures and the font, publishes the values the pages use, and presses the game's
  buttons for the menu shortcuts.

## Building

Requirements (built and tested with clang 23.1.4): `clang`, `lld`, `llvm-objcopy` / `llvm-nm` / `llvm-strip`, Python 3, and an Eden Duo
source checkout (only `src/core/mods/dsmod_module_abi.h` is read).

```
tools/so2r/make_package.sh /path/to/eden-duo         # -> dist/010065301A2E0000-StarOceanTheSecondStoryR-<version>.dsmod.zip
```

This regenerates the pages, builds the module for `android-arm64-v8a` and `linux-x86_64`, and packs
everything with the repository's `tools/build_dualscreen_package.py`. `--diag` after the path builds
a variant with a diagnostics page (`dist/010065301A2E0000-StarOceanTheSecondStoryR-<version>-diag.dsmod.zip`), for reporting problems.

Rebuilding the code patch (only needed if `tools/so2r/hidehud/stub.S` changes):

```
python3 tools/so2r/hidehud/build_plan.py packages/StarOceanTheSecondStoryR/dualscreen/plans/D214BA64D902AEDA4197B57DEBABD01B00000000000000000000000000000000.json
python3 tools/so2r/hidehud/check_plan.py packages/StarOceanTheSecondStoryR/dualscreen/plans/D214BA64D902AEDA4197B57DEBABD01B00000000000000000000000000000000.json [main]
```

(`check_plan.py` also compares the hook's bytes with the game's `main` when it is given.)

Tests (synthetic game files and guest memory, no game files needed; run after `make_package.sh`):

```
tools/so2r/run_tests.sh /path/to/eden-duo    # module test: PASS; marker test: 158 checks, 0 failures
```

`pictures.idx` is made from a game dump with `tools/so2r/build_picture_index.py` (names and positions
only; needs `pip install UnityPy Pillow lz4`); `tools/so2r/merge_pictures.py` adds pictures at the end
without changing existing lines.
