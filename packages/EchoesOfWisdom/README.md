# The Legend of Zelda: Echoes of Wisdom companion

Title `01008CF01BAAC000`, game update 1.1.0 (build `9F221E1AFA65BA5443E955158AB97DA871E5E41F…`).
Companion 1.0.0 for Eden Duo 1.3.2 (runtime 22) or newer. Any other build shows a notice and
reads nothing.

The bottom screen is a map-first companion: terrain, Echoes, Notebook/Items/Equipment and quick
travel without opening the pause menu.

- **Map** (home page): pan-and-zoom Field terrain with the game's own place names and map icon,
  a right-hand HUD rail (Bind/current Echo/Swordfighter Form), active-rift clipping, companion
  map pins (up to 24, local to the emulator profile) and a waypoint picker for quick travel to a
  revealed, unlocked Field destination.
- **Held Echo selector**: hold Right on the physical D-pad during gameplay for a six-column,
  three-row grid of learned Echoes with sort tabs (Last Used, Most Used, Last Learned, Cost,
  Type); release to confirm the steered native selection. The companion never casts an Echo.
- **Notebook, Items and Equipment**: a shared five-column collection grid and detail pane. Equip,
  remove, eat or drink where the native game allows it; these buttons steer the original controls
  and wait for native readback rather than writing inventory state directly.
- **Major dungeons**: the eight major dungeons' own room artwork and floor definitions, with
  per-floor exploration and a shared coordinate frame across floors.
- An opening-scene view (Suthorn Ruins) during the verified prologue, with Bow/Sword/Bomb button
  prompts; ordinary pages and the Echo/Bind/Swordfighter rail stay hidden there.

The package ships no game art. Icons, the map, place names, fonts and all text are read from the
player's own game files and session at runtime.

## Layout

| Path | What it is |
|---|---|
| `dualscreen/manifest.json` | Pages, widgets, actions and bindings. |
| `dualscreen/load-plans/<build id>.json` | Guest load plan: the format-2 helper plus its patched call site, gated to this build. |
| `native/modules/echoes_module.cpp`, `echoes_*.h`/`.cpp` | The native module (readers, pages, catalog and the action bridge). |
| `native/modules/echoes_*_test.cpp` | Host unit tests. |
| `tools/echoes-of-wisdom/hook.S`, `build_echoes_helper.py` | Guest helper (AArch64 assembly) that the load plan installs, and its builder. |
| `tools/echoes-of-wisdom/gen_manifest.py`, `stamp_manifest.py`, `quick_slot_manifest.py` | Manifest generator and its shared piece builders. |
| `tools/echoes-of-wisdom/HELPER-TOOLCHAIN.md` | The guest helper's toolchain recipe and hook inventory. |

This README sits outside `dualscreen/` on purpose: the packager archives `dualscreen/` as is,
and keeping the README out leaves the archive identical to the published 1.0.0 zip.

## Rebuilding

Release modules, with the 1.0.0 flags (stripped hashes are listed in the script):

```sh
EDEN_SOURCE_ROOT=/path/to/eden-duo ANDROID_NDK=/path/to/ndk/28.2.13676358 \
    tools/echoes-of-wisdom/build_modules.sh build-echoes
```

Or through CMake with the other modules (`native/README.md`): target `dsmod-echoes`, and with
`-DBUILD_TESTING=ON` one `dsmod-echoes-*` test per `echoes_*_test.cpp`.

Load plan (needs clang and the LLVM binutils; see `tools/echoes-of-wisdom/HELPER-TOOLCHAIN.md`
for the hook inventory and `tools/echoes-of-wisdom/tests/` for its builder's own tests):

```sh
tools/echoes-of-wisdom/build_echoes_helper.py --hook-kind entry \
    --hook-address <addr> --original-bytes <hex> --output <out-dir>
cp <out-dir>/plan.json \
    packages/EchoesOfWisdom/dualscreen/load-plans/9F221E1AFA65BA5443E955158AB97DA871E5E41F000000000000000000000000.json
```

Package:

```sh
tools/build_dualscreen_package.py --package packages/EchoesOfWisdom --output dist \
    --version 1.0.0 --min-runtime 22 \
    --module android-arm64-v8a=build-echoes/android-arm64-v8a/01008CF01BAAC000.so \
    --module linux-x86_64=build-echoes/linux-x86_64/01008CF01BAAC000.so \
    --build-id 9F221E1AFA65BA5443E955158AB97DA871E5E41F000000000000000000000000
tools/compact_zip.py dist/01008CF01BAAC000.dsmod.zip
```

With byte-identical modules this reproduces the published
`01008CF01BAAC000-EchoesOfWisdom-1.0.0.dsmod.zip`
(sha256 `36923d5e1cc0cbcef3b82685033ca4a8b005c9307c9e7ebdbf9074a4b6870a35`).

The manifest is generated by `tools/echoes-of-wisdom/gen_manifest.py`; the scripts that first
derived its native pixel geometry worked on local research data and game files, so they are not
part of this repository.
